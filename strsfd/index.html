GIT / GITHUB

Importanța utilizării aplicațiilor de lucru în echipă

01 — Fundamente

Ce este Git?

Git este un sistem distribuit de control al versiunilor, creat de Linus Torvalds în 2005. Urmărește fiecare modificare a codului și permite colaborarea mai multor developeri.

Ce este GitHub?

GitHub este o platformă cloud pentru găzduirea repository-urilor Git, cu funcții de colaborare: pull requests, issues, code review, Actions.

02 — Fluxul de lucru în echipă

Fork & Clone — fiecare membru are o copie locală a proiectului.
Branch — fiecare funcție se dezvoltă pe un branch separat.
Pull Request — modificările sunt revizuite de colegi.
Merge & Deploy — codul aprobat este integrat în main.

03 — De ce contează

Siguranța codului — nicio modificare nu se pierde.
Productivitate — mai mulți developeri lucrează simultan.
Transparență — fiecare commit arată cine, ce și de ce a modificat.
CI/CD — GitHub Actions testează și publică automat.
Colaborare remote — echipe din whole lume lucrează împreună.
Documentare — commit-urile și PR-urile documentează proiectul.
